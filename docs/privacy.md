# 隐私

## 默认完全离线

不开启联网时，MinIME 不连接任何服务器：

- 打字、候选、学习、整句模型都在本机完成；
- 离线语音在本机识别，录音不会离开这台电脑；
- 唯一的网络访问是安装后运行 `minime-fetch` 时，从腾讯官方地址下载引擎、词库和模型。

## 开启联网之后

联网由「MinIME 设置 → 跨设备 → 联网」总开关控制，各个功能还有单独的开关：

| 功能 | 默认 | 发送给服务器的内容 |
|---|---|---|
| 关联设备 | — | 匿名设备身份、设备名（默认 `Linux`，不读取主机名） |
| 剪贴板（文本） | 开（受总开关控制） | 复制的文本 |
| 剪贴板（图片） | 关 | 图片（经腾讯云对象存储中转） |
| 常用语 | 随关联启用 | 常用语的快捷字母和短语 |
| 同步个人词库 | 关 | 用户词库（经腾讯云对象存储中转） |
| 换机助手 | 手动发起 | 本机用户词库（加密后上传，供手机下载） |
| 云输入 | 关 | 每次按键的拼音和光标前的文字 |

需要了解的几点：

- **服务器可以读取同步的内容。** 传输由 TLS 保护，第三方无法窃听；但协议本身不是端到端加密，
  剪贴板、常用语、个人词库在腾讯服务器上都可以被解密。这是官方协议的设计，MinIME 无法改变，
  和使用官方客户端时一样。
- **匿名身份**：netd 使用随机生成的匿名设备身份，不需要也不会关联微信账号。
- **MinIME 不发送已上屏的文字和使用日志。** 开启云输入时，netd 只放行云输入请求；开启个人词库同步时，
  只放行词库同步相关的请求；其他请求一律不发出。
- **图片链接即凭据**：经对象存储中转的图片和词库包靠下载链接访问，所以图片同步默认关闭。

## 本机数据

| 数据 | 位置 | 权限 |
|---|---|---|
| 用户词库 | `~/.local/share/minime/userdata/` | 用户目录默认权限 |
| 设备身份、常用语 | `~/.local/share/minime/net/` | 目录 0700，文件 0600 |
| 换机助手的备份 | `~/.local/share/minime/net/migration/` | 目录 0700，文件 0600 |
| 删除的词 | `~/.local/share/minime/blocked_words.txt` | 用户目录默认权限 |

各个服务只监听本机 Unix socket（目录 0700、socket 0600），其他用户无法连接。

## 输入框

- **密码框**：按键直接交给应用，不经过引擎，不学习，不发任何请求。
- **隐私输入框**（应用声明为敏感数据的输入框）：可以正常输入，但不向引擎提供周围文字、不学习整句、
  不使用云输入，引擎也不学习这里的选词（0.1.1 起）。之前学到的词照常出现。

## 删除数据

```bash
systemctl --user stop minime-engined minime-netd
rm -rf ~/.local/share/minime/userdata     # 用户词库（学习结果）
rm -rf ~/.local/share/minime/net          # 设备身份、常用语、迁移备份
```

删除设备身份后，再次开启联网会生成新的匿名身份，需要重新关联设备。
