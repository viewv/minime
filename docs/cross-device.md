# 跨设备功能

跨设备功能由网络服务 `minime-netd` 提供，和手机上的微信输入法互通。**这些功能默认全部关闭，不开启就不联网。**

```bash
systemctl --user enable --now minime-netd
```

然后在「MinIME 设置 → 跨设备」里打开「联网」。开启后，netd 以匿名设备身份连接微信输入法服务器，
不需要登录微信，也不需要微信账号。设备身份保存在 `~/.local/share/minime/net/identity.json`（权限 0600）。

关于各个功能会把哪些数据发给服务器，见 [privacy](privacy.md)。

## 关联手机

1. 在「跨设备」页点「关联设备」，页面显示 6 位匹配码；
2. 手机打开微信输入法 →「跨设备粘贴和同步」→「关联我的其他设备」，输入匹配码。

也可以反过来：在手机上查看本机匹配码，输入到设置程序里。一个设备组可以有多台设备。
「我的设备」列出已关联的设备，可以解除关联；本机在手机上显示的名字可以在「本机」一节修改（默认是 `Linux`，
不会读取主机名）。

## 剪贴板

关联后，在一台设备上复制的内容会出现在其他设备的剪贴板里。

- **文本**：默认开启。超过 256 KB 的文本不同步。
- **图片**：默认关闭。图片要经腾讯云对象存储中转，下载链接泄露时他人可以看到图片，所以需要单独打开。
- 被密码管理器标记为密码的内容（`x-kde-passwordManagerHint`）不同步。只有设置了这个标记的程序才能识别，
  例如 KeePassXC。
- 只同步 netd 启动之后的复制，启动时剪贴板里已有的内容不会发出。
- 剪贴板使用 `wl-clipboard`（`wl-copy` / `wl-paste`），需要 Wayland 会话。

## 常用语

「常用语」页管理快捷短语：输入快捷字母（例如 `sss`）时，短语排在候选第一位。开启联网并关联设备后，
常用语和手机双向同步。

## 同步个人词库

「跨设备 → 同步个人词库」（默认关闭）：在关联的设备之间同步打字学到的词。
同步由引擎自己调度（启动后和词库变化时），全量词库包经腾讯云对象存储中转，第一次上传较慢。

## 换机助手

把手机上的个人词库迁移到本机，不需要关联设备：

1. 在「跨设备 → 换机助手」点「开始」，页面显示二维码；
2. 手机打开微信输入法 →「换机助手」→「扫一扫」。

本机会先导出一份当前用户词库作为备份（保存在 `~/.local/share/minime/net/migration/`），再导入手机的词库，
导入后立即生效。手机的设置目前只读取、不应用。

**已知问题**：第一次迁移时，手机一侧的进度可能停在 40%。本机的导入不受影响。

## 云输入（实验）

「跨设备 → 云输入」（默认关闭）：打字时把拼音和光标前的文字发给服务器，换回云端候选（标 `☁`），
例如网络新词。云输入只在全拼下使用，在隐私输入框里自动停用。云端候选有最长约 800 ms 的等待上限，
网络慢时不影响本地候选的显示。

## 命令行

日常不需要命令行；需要时：

```bash
minime-netd status          # 连接状态、已关联的设备
minime-netd pair            # 显示本机匹配码
minime-netd pair 123456     # 输入手机上显示的匹配码
minime-netd unpair <设备>    # 解除某台设备（unpair all 解除全部）
minime-netd migrate         # 在终端里显示换机助手的二维码
```

## 实现

`minime-netd` 用 Rust 从协议层重新实现了官方客户端的网络栈：WebSocket 连接、ECDH 密钥交换、AES 加密、
请求签名和 protobuf 消息，不调用任何腾讯的程序。引擎自己发出的网络请求（云输入、个人词库同步）
由 engined 的网络兼容层经 Unix socket 交给 netd，netd 按白名单决定是否发出。

连接断开后 netd 自动重连（间隔从 1 秒逐步增加到 60 秒），网络问题不会影响打字。
