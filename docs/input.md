# 输入功能

候选、词库和学习都由官方引擎完成；MinIME 负责把引擎接到 fcitx5 上，并补上桌面端需要的前端功能。
大部分选项在「MinIME 设置」的「输入」页里，也可以在 fcitx5 自带的配置界面里修改，两边改的是同一个文件。

## 输入方案

| 方案 | 说明 |
|---|---|
| 全拼 | 默认。支持简拼（`nh` → 你好）、14 项模糊音、整句候选和云输入 |
| 双拼 | 小鹤、自然码、微软、搜狗、紫光、拼音加加、智能 ABC。搜狗、微软、紫光把 `;` 当韵母键 |
| 五笔 | 86 版、98 版、新世纪版。可选第五码顶字上屏（默认开）、四码唯一候选自动上屏、拼音混输 |

双拼和五笔由引擎原生支持。整句候选和云输入只理解全拼，在双拼和五笔下不启用。
切换五笔版本时引擎服务会重启一次（五笔码表在启动时加载）。

## 按键

| 按键 | 组合中 | 没有组合时 |
|---|---|---|
| 字母 | 交给引擎 | 开始组合 |
| 大写字母 | 原样交给引擎（`woyongiPhone` → 我用iPhone） | 开始组合 |
| `1`–`9` | 选当前页第 n 个候选 | 交给应用 |
| 空格 | 选高亮的候选 | 交给应用 |
| 回车 | 把打的字母原样上屏 | 交给应用 |
| Esc | 清空组合 | 交给应用 |
| 退格 | 删一个字母 | 交给应用 |
| Shift+退格、Ctrl+退格 | 删一个音节 | 交给应用 |
| Ctrl+A 后按退格或 Delete | 清空组合 | 交给应用 |
| Ctrl+Delete | 删除高亮的候选（以后不再出现） | 交给应用 |
| ← ↑ / → ↓ Tab | 移动高亮 | 交给应用 |
| `-` PageUp / `=` PageDown | 翻页 | 交给应用 |
| 标点 | 上屏当前候选，后面跟中文标点 | 输入中文标点 |
| 其他 Ctrl / Alt 组合键 | 先把字母原样上屏，再交给应用 | 交给应用 |

候选框支持鼠标点选、翻页按钮和滚轮。候选按需加载，生僻字可以一直往后翻到。

## 候选

- **整句候选**（标 `✦`）：用官方整句模型生成的整句，结合光标前的文字排序，见 [whole-sentence](whole-sentence.md)。
  打错字时（引擎判断做了纠错）整句候选不会抢第一位。
- **常用语**（标 `⬡`）：输入设置好的快捷字母时，对应的短语排在第一位。常用语在「常用语」页管理，可以和手机同步。
- **云候选**（标 `☁`）：开启云输入后，服务器返回的候选，见 [cross-device](cross-device.md)。
- **表情**：可选 Emoji（默认）、颜文字或不显示。打「哈哈」「点赞」时出现在候选里。
- **日期和时间**：打 `riqi`、`shijian` 时给出当前日期和时间的几种写法。
- **上下文**：插件把光标前的文字告诉引擎，引擎据此调整排序（例如「疑是地上」之后打 `shuang`，首选是「霜」）。
  应用不提供周围文字时，用本输入框最近输入的内容代替。

## 删除学错的词

误选过的词有时会排到前面。组合中按 **Ctrl+Delete** 删除高亮的候选，或在候选上点**右键 →「删除这个词」**。
删除的词加进引擎的用户屏蔽表，以后不再出现，重启后依然有效。删除记录保存在
`~/.local/share/minime/blocked_words.txt`。

## 中英文和标点

- **大小写混打**：大写字母和小写一样交给引擎，引擎认得 iPhone、PDF 这类词。
- **单按 Shift 切换中英文**：默认关闭。打开后，按下 Shift 不按别的键就松开，切换中/英；
  切到英文时正在组合的字母原样上屏。
- **中英文标点**：默认中文标点。快捷键（默认 Ctrl+.）随时切换，切换时屏幕上有提示。
- **自动加空格**：「中文和英文之间」「中文和数字之间」两个开关，默认关闭。打开后在汉字和英文、数字相邻处自动补一个空格，
  标点前后不加。

## 繁体

打开「繁体输出」后，候选和上屏的文字使用繁体（台湾字形）。整句候选依赖 OpenCC 做简繁转换，没有安装 OpenCC 时繁体模式下不出整句候选。

## 隐私输入框

- **密码框**和应用要求关闭输入法的输入框：按键直接交给应用，不经过引擎。
- **标记为隐私的输入框**（例如 Qt 的 `ImhSensitiveData`）：可以正常输入，但不向引擎提供周围文字，
  不学习整句和选词，也不使用云输入（之前学到的词照常出现）。

## 离线语音

按住右 Alt 说话，松开上屏；也可以按 Ctrl+Alt+空格开始和结束。见 [voice](voice.md)。

## 配置项

配置文件是 `~/.config/fcitx5/conf/minime.conf`，主要选项：

| 键 | 默认 | 说明 |
|---|---|---|
| `InputScheme` | `Quanpin` | `Quanpin` / `Shuangpin` / `Wubi` |
| `ShuangpinScheme` | `Xiaohe` | `Xiaohe` / `Ziranma` / `Microsoft` / `Sogou` / `Ziguang` / `PinyinJiaJia` / `ABC` |
| `WubiTopCommit` / `WubiUniqueCommit` / `WubiPinyin` | 开 / 关 / 关 | 五笔选项 |
| `WholeSentence` | 开 | 整句候选 |
| `Traditional` | 关 | 繁体输出 |
| `EmojiMode` | `Emoji` | `Emoji` / `Kaomoji` / `None` |
| `PageSize` | 9 | 每页候选数（3–9） |
| `ShiftToggle` | 关 | 单按 Shift 切换中英文 |
| `AsciiPunct` | 关 | 使用英文标点 |
| `PunctToggleKey` | Ctrl+. | 中英文标点切换快捷键 |
| `AutoSpaceAbc` / `AutoSpace123` | 关 | 中文和英文、数字之间自动加空格 |
| `VoiceHoldKey` | `RightAlt` | 长按说话的键：`RightAlt` / `LeftAlt` / `None` |
| `VoiceKey` | Ctrl+Alt+空格 | 语音输入快捷键 |
| `[Fuzzy]` 一节 | 全关 | 14 项模糊音（z/zh、c/ch、s/sh、n/l、r/l、h/f、g/k、an/ang、en/eng、in/ing、ian/iang、uan/uang、hui/fei、huang/wang） |
| `[Network]` 一节 | 全关 | 联网功能，见 [cross-device](cross-device.md) |

## 已知的不足

- 没有上屏后的联想弹框。桌面端打字时下一个词由上文排序改善，见上面的「上下文」。
- 英文单词的拼写纠错很弱（引擎在拼音会话里基本不纠正英文）。
