# 词库与学习

## 内置词库

引擎使用官方 Windows 安装包自带的词库和模型（`BuildIn/` 目录，约 220 MB，由 `minime-fetch` 下载）：
中文主词库、中英混合词库、语言模型、二级词库、纠错和排序模型、五笔码表等。

「MinIME 设置」的「词库」页列出这些词库，可以单独关闭某一项（例如用不到的五笔码表）。
内置词库只在引擎启动时加载，改动后点页面底部的「重启引擎」生效。

### 五笔码表

三个五笔版本（86、98、新世纪）各有一份码表。MinIME 只把其中一份交给引擎：按 86、98、新世纪的顺序，
取第一个没有关闭的。在「输入 → 五笔版本」里选择版本时，设置程序会关闭另外两份并重启引擎。

## 专题词库

专题词库（官方称为「细胞词库」）是可以单独加载的小词库，改动立即生效，不需要重启引擎：

| 词库 | 内容 |
|---|---|
| 高频短语 | 聊天里常用的口语短语 |
| 符号 | 用拼音打出 ♠ ♥ → 等符号 |
| 微信读书 | 书名、作者和文学词汇 |

在「词库」页可以开关这些词库，也可以用「导入词库文件…」加载官方格式（`cell_dict.*.zh`）的词库文件。

## 用户词库和学习

引擎会记住你的选择：选过的词以后排得更靠前，新组合的词会被记住。这些数据保存在用户词库里：

```
~/.local/share/minime/userdata/DictDir2/
```

- 用户词库在重启之间保留。备份这个目录就备份了全部学习结果。
- 选中整句候选时，MinIME 会在后台让引擎把这句话也学进用户词库（见 [whole-sentence](whole-sentence.md)）。
- 删除学错的词：组合中按 Ctrl+Delete，或在候选上点右键（见 [input](input.md)）。

## 同步和迁移

开启联网后，用户词库可以和手机同步（「跨设备 → 同步个人词库」，默认关闭），
也可以用「换机助手」把手机上的个人词库迁移到本机。见 [cross-device](cross-device.md)。

## 其他平台的词库

各平台（Windows、macOS、安卓、iOS）的官方词库大多相同。桌面引擎可以加载部分其他平台的词库，
但手机独有的词库大多服务于联想、英文键盘、九宫格、手写等桌面端没有的功能，加载后看不到效果。
「词库」页把这类词库单独列出，作为实验功能。
